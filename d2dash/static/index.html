Output tests

Each button pulses a real part once. Engine running, handbrake on, nobody near the fan. These frames were decoded from captures and have not yet been fired from this software on a car: treat the first use of each as a test.

Security

Learn security code puts the ECU into learn mode so it re-pairs with the BCU. It is not wired up yet: the library has never sent that frame, and a failed learn leaves the car immobilised.
